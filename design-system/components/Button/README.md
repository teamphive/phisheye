Der Hauptbutton ist blau (`primary`), alle anderen bleiben neutral.

- Pro Ansicht höchstens ein Hauptbutton, zum Beispiel "Neue Analyse".
- Sekundär: `muted` oder Rahmen `input`. Tertiär: nur Text.
- Löschen ist neutral mit rotem Text (`destructive`), erst im Dialog rot gefüllt.
- Radius `radius-md`, Fokus als 2 px Ring in `ring`.
