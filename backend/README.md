# phisheye backend

FastAPI-Backend für phisheye.

## Ausführen

```bash
uv run uvicorn app.main:app --reload
```

Läuft dann unter `http://localhost:8000`, Docs (Swagger UI) unter `http://localhost:8000/docs`.

## Stand

Aktuell nur Grundgerüst (`app/main.py`), noch kein DB-Anschluss, keine Routen.
